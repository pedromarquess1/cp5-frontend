Política de privacidade

Como tratamos informações neste projeto

Este site foi desenvolvido como um projeto acadêmico para apresentação da landing page do aplicativo Melodia. Ele tem caráter demonstrativo e não representa um serviço de produção real, cadastro comercial ou coleta de dados em ambiente de produção.

Os formulários presentes neste projeto foram implementados com finalidade de estudo front-end. Não há backend real, banco de dados, autenticação ou infraestrutura de armazenamento ativa conectada à demonstração.

Os e-mails inseridos em campos de newsletter ou contato não são efetivamente enviados ou persistidos em um servidor externo. O objetivo é apenas validar a interface, a experiência do usuário e o comportamento do formulário em front-end.

Se um futuro projeto real for desenvolvido, a política de privacidade deve ser revisada e ampliada com base na infraestrutura, no consentimento do usuário e nas exigências legais aplicáveis.

Este projeto pode utilizar armazenamento local do navegador para manter preferências de tema, como dark mode, apenas para melhorar a experiência do usuário dentro do ambiente de demonstração.

Para dúvidas sobre o projeto, o contato pode ser feito pela página de contato.
